# Scientific Calculator 🧮

**Website:** https://parvanamohan.github.io/Scientific-Calculator/

## 📌 About the Project

Scientific Calculator is a simple, responsive web-based calculator designed to perform basic arithmetic and advanced scientific calculations.

It provides an easy-to-use interface for students and anyone who needs quick, accurate mathematical calculations.

## ✨ Features

- Basic arithmetic operations
- Decimal calculations
- Brackets and complex expressions
- Trigonometric functions: sin, cos, tan
- Inverse trigonometric functions
- Degree (DEG) and Radian (RAD) modes
- Logarithm (log), natural logarithm (ln), and antilogarithm
- Squares, powers, square roots, and factorials
- Mathematical constants: π and e
- Reciprocal calculations
- Calculation history
- Keyboard support
- Light and dark themes
- Error handling for invalid expressions
- Responsive design for desktop and mobile devices

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Use

1. Open the website using the link provided above.
2. Enter a mathematical expression using the calculator buttons or keyboard.
3. Select the required scientific function.
4. Choose DEG or RAD mode for trigonometric calculations.
5. Press the equals button to view the result.
6. Use the clear button to start a new calculation.

This project was developed as an educational project to practise front-end web development and JavaScript-based mathematical operations while building a practical tool for everyday calculations.
